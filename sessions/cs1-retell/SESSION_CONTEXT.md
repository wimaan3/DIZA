## Decisions made
1. **Config-as-code:** prompts are split into `_shared_rules.md` (hard rules, included in every agent) plus a per-agent prompt. Tools are defined once in `tools.json`. `push.py` assembles them and creates/updates the LLM + agent. IDs live in `agents/retell.ids.json` (as proposed in PR #1).
2. **staging/prod:** Retell's API can't set version tags. `staging` = update drafts only (swaps → `latest`); `prod` = publish (swaps + number → `latest_published`).
3. **Model:** `gpt-4.1-mini`, temperature 0.1, `tool_call_strict_mode` on. Voice `cartesia-Cleo` (`sonic-3`, multilingual). Language `["en-US","es-419"]` (LA Spanish; `"multi"` isn't a valid value).
4. **Opening line:** generated by the LLM (no fixed `begin_message`) so it can branch on `{{zone_level}}` and speak the recording notice. Retell bills a 10 s minimum for a dynamic opening; negligible.
5. **Transfer to a human:** `warm_transfer` to `{{oncall_number}}` (set by `route_to_human` response variables), 20 s ring, whisper via the private handoff message. `show_transferee_as_caller=false`, because caller-ID override fails on some carriers. Agentic warm transfer needs an extra transfer agent: possible upgrade.
6. **988 safety:** `transfer_to_crisis_line` dials `{{crisis_line_number}}`, which comes from env vars. **During the hackathon it must be a teammate's phone**: drill cards role-play self-harm, and we must not send them to the real Lifeline. If the transfer fails, the agent tells the caller to call/text 988.
7. **911:** the agent never transfers to 911. It tells the caller to hang up and dial 911 (same reason: drills).
8. **Swaps:** inbound ↔ crisis, checkin → crisis. Post-call analysis = destination agent; webhooks = both agents; voice and language kept across the swap.
9. **Privacy settings:** `data_storage_retention_days=7`, post-call PII scrubbing for SSN, card, bank, password, PIN, passport and license numbers. Names, addresses and phones stay unscrubbed, because the backend needs them for callbacks.
10. **Folded in early from M2** because it was cheap: boosted keywords, interruption sensitivity 0.75/0.8, 8 s reminder, longer silence timeout on crisis (90 s), DTMF on, `register_volunteer`.
